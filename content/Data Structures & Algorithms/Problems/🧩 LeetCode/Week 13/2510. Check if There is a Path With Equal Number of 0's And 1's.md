## 📝 Problem Details

- **Title:** `2510. Check if There is a Path With Equal Number of 0's and 1's`
- **Link:** https://leetcode.com/problems/check-if-there-is-a-path-with-equal-number-of-0s-and-1s/
- **Difficulty:** #Medium 
- **Tags/Categories:** `{{tags/categories}}`

> input binary matrix `grid`
> you can move down or right
> return `true` if there is a path from `0,0` to `m-1, n-1` that visits an equal number of 0s and 1s

