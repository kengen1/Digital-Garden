## 📝 Problem Details

- **Title:** `151. Reverse Words in a String`
- **Link:** https://leetcode.com/problems/reverse-words-in-a-string/
- **Difficulty:** #Medium 
- **Tags/Categories:** 

> input string `s`, reverse the order of the words 
> **word** --> a sequence of non-space characters 
> return a string of the words in reverse order concatenated by a single space 
## 💭What Were My Initial Thoughts?

```
- O(n) additional space solution:
	- itearte from back to front, looking for the occurrence of a space
	- push these non-space elements into an intermediary string
	- once we encounter a space, reverse the substrnig and then push it into a result string
	- push the index pointer forward until the next nonspace char
	- return the result after going through the entire string 

- O(1) solution:
	- first reverse the entire input string 
	- iterate from the front of the string to the back 
	- until we encounter a space, upon which we reverse the substr from first index to current index 
```
