## 📝 Problem Details

- **Title:** `2402. Meeting Rooms III`
- **Link:** https://leetcode.com/problems/meeting-rooms-iii/
- **Difficulty:** #Hard 
- **Tags/Categories:** `{{tags/categories}}`

> input integer `n`
> 	there are `n` rooms numbered from `0` to `n-1`
> 	
> input 2D array `meetings` where `meetings[i] = [start,end]`
> 	all values of `start` are unique
> 
> Meetings are allocated to rooms in the following manner:
> 	1. each meeting will take place in the unused room with the **lowest number**
> 	2. if there are no rooms available, delay the meeting until one is free
> 		- the delayed meeting should have the same duration (start late, finish late)
> 	1. when a room becomes unused, meetings that have an earlier original start time should be given the room

> return the number of the room that held the most meetings
> if there are multiple rooms, return the room with the lowest number
