## 📝 Problem Details

- **Title:** `994. Rotting Oranges`
- **Link:** https://leetcode.com/problems/rotting-oranges/
- **Difficulty:** #Medium 
- **Tags/Categories:** #Graphs 

> input matrix `grid` of size `m * n`
> each cell in `grid` can have three possible values:
> 	`0` --> empty cell
> 	`1` --> fresh orange
> 	`2` --> rotten orange
> every minute any fresh orange that is **4-directionally adjacent** to a rotten orange becomes rotten
> return the min number of minutes that must elapse until there are no cells with a fresh orange
> return -1 if impossible
